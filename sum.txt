# Smart Summarize Auto

Auto-selects best method by content.

name: smart-summarize
description: Select summarization method by content type. Use when user asks to summarize without specifying method.

## Method Selection

Complex concept or theory: feynman.
Book or textbook: adler.
Article or blog post: sq3r.
Lecture video or meeting: cornell.
Facts definitions vocabulary: spaced.
Academic paper: retrieval.
Multiple related concepts: concept-map.
Full synthesis needed: condense.

## Workflow

1. Identify content type + user goal
2. Select method from table
3. Announce: Usando metodo [X] porque [reason]
4. Apply method
5. Deliver summary with frontmatter

## Shared Sections

All sub-skills use these.

### Output Frontmatter

created: YYYY-MM-DD
updated: YYYY-MM-DD
method: [method name]
source: [title or URL]
tags: [relevant tags]

### Source Processing

Extract source text before applying method.
PDF selectable: pdftotext file.pdf
Scanned PDF: OCR first then extract text
Large PDF: extract page range
URL: fetch and extract readable content
YouTube or video: fetch transcript
Text or Markdown: read directly

Extract to plaintext. On failure, ask user for alternative format.

### Language

- Spanish default
- Technical terms in English when standard
- Clear direct no filler
