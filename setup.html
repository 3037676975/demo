你要做的 5 步

1
打开 Supabase

进入 supabase.com，登录，点 New project，新建一个项目。

2
运行 SQL

进 SQL Editor，点 New query，把右侧 SQL 复制进去，点 Run。

3
复制 Project URL

在 Project Settings → API 里找到 Project URL。

4
复制 service_role key

同一个页面找到 service_role key。这个是密钥，只能填到 Vercel，不能发给别人。

5
填到 Vercel 环境变量

在 Vercel 项目 Settings → Environment Variables 添加 SUPABASE_URL、SUPABASE_SERVICE_ROLE_KEY、ADMIN_PASSWORD，然后 Redeploy。

不要把 service_role key、token、password 发到聊天里。

SQL 建表语句

复制下面内容到 Supabase 的 SQL Editor 运行。

Vercel 要填写的环境变量

A
SUPABASE_URL

填 Supabase 的 Project URL。

B
SUPABASE_SERVICE_ROLE_KEY

填 Supabase 的 service_role key。只能放 Vercel，不能公开。

C
ADMIN_PASSWORD

你自己设置的后台发布密码，比如一串你记得住的密码。

填完环境变量后，一定要 Redeploy。否则接口还是读不到新变量。
